Comandos básicos de Linux

Primeros comandos de navegación y manejo de archivos practicados en la terminal, base para todo lo que sigue.

ComandoQué hace
pwdMuestra el directorio actual
lsLista archivos y carpetas
cdCambia de directorio
cd ..Sube un nivel en el árbol de directorios
mkdirCrea una carpeta
touchCrea un archivo vacío
catMuestra el contenido de un archivo
nanoEdita un archivo desde la terminal
cpCopia archivos o carpetas
mvMueve o renombra archivos
rmElimina archivos
