# kali-linux-lab

Registro técnico de práctica con Kali Linux en un entorno virtualizado con VirtualBox. Documento acá los comandos, configuraciones y ejercicios a medida que los voy resolviendo, como parte de mi transición hacia ciberseguridad.

## 🌐 Sitio

Las entradas están publicadas como una web simple con GitHub Pages:
**[juanpablocode-sudo.github.io/kali-linux-lab](https://juanpablocode-sudo.github.io/kali-linux-lab/)**

## 📁 Estructura

```
docs/
├── index.html              # landing con el listado de entradas
└── entradas/
    └── 01-comandos-basicos.html
```

Cada entrada nueva se agrega en `docs/entradas/` y se enlaza desde `docs/index.html`.
